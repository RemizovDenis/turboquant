# Security Policy

## Supported versions

Security fixes are provided for the current active release line in `main` and the latest release branch.

## Reporting vulnerabilities

Do not open public issues for security vulnerabilities.

Use one of these channels:

- Email: remizovcrypto@gmail.com
- GitHub Security advisory: "Report a vulnerability" in the Security tab

## What to include

- affected component/file
- impact and exploit scenario
- minimal reproduction
- proposed mitigation (if available)

## Response targets

- acknowledgement within 48 hours
- triage decision within 5 business days
